## Coupling notes

- `:app` is a broad composition root and depends directly on most modules.
- `:data:network` depends on `:data:database` and `:data:preferences`; it is therefore not a pure transport-only leaf.
- `:data:sync` depends on `:data:network` and Room and owns WorkManager/unified-sync orchestration.
- `:data:operations` intentionally spans several feature contracts for cross-feature transactions.
- `:feature:dashboard:api` is the lightweight public contract used by feature contributors for Home search/actions/events.
- Customers and suppliers are not separate modules: both are owned through `:feature:party`.
- Logistics is implemented by `:feature:shipment`; there is no `:feature:logistics` module.
