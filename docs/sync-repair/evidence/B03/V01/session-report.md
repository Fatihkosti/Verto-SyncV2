## Implemented

- Added version authority, local generation, immutable mutation/snapshot, pending-reference, sealed-batch/member, inbox-group, migration-evidence-v2, and expense-revision stores.
- Split cursor receipt fields from the applied checkpoint and preserved legacy cursor values during migration.
- Added the attachment retry/verification/cancellation lifecycle fields.
- Added fixed-point Minor columns for cash reconciliation and denominations. Existing finite `Double` values are converted once through `Money.fromLegacyDouble` (`scale=2`, `HALF_UP`); non-finite/overflow values abort the Room migration with `MONEY_MIGRATION_REVIEW_REQUIRED`, leaving the old transaction intact for review.
- Added transactional DAO primitives that keep observed and applied server versions separate, represent unknown versions as `NULL`, enforce monotonic applied versions, and allocate local generations from stored CAS state rather than wall-clock time.
- Enforced zero-based contiguous sealed-batch membership before persistence and SQLite checks/indexes for invalid structural rows. Migration evidence deliberately has no cascading FK to heterogeneous source queues.
