## Implemented

- Immutable `Sales Return / Credit Note` and `Purchase Return / Debit Note` aggregates linked to original invoice lines.
- Room 68→69 tables, foreign keys, write identity, immutability guards, over-return guards, payment-allocation guards, and void-after-return guard.
- Original posted invoice is never rewritten by the return coordinator.
- Duplicate/retry handling uses stable `writeId`; same-write retry is resolved before concurrent quantity recheck.
- Sales return restores stock using historical `unitCostAtSale`, reverses historical COGS, and does not update current/latest purchase price.
- Purchase return deducts stock and only rolls latest price back when the returned source still owns the latest valid cost event.
- A newer purchase/receipt prevents silent price rollback.
- International purchase returns are limited to quantity actually posted through logistics receipt linkage; no stock return is guessed from invoice quantity.
- Cash refund and party credit/debit-note settlement are in the owner transaction.
- F252 cash path stays in `Long` minor units through the coordinator, app adapter, cash manager, and cash DAO. Legacy `Double` fields are compatibility projections only.
- Return payment allocations are bounded by effective trusted, unreversed payments.
- Multi-currency functional values are derived from the immutable original recognition ratio; unknown historical currency/cost fails closed.
- Financial outbox adds `INVOICE_RETURN_POSTED`; sync materializes immutable return facts without replaying local stock/cash side effects.
- Server SQL validates original invoice/line identity, exact monetary facts, cumulative return quantities, payment allocations, cash refunds, historical FX ratio, international receipt quantity, idempotency, and void conflicts.
- F250 reporting integration corrected: sales returns reduce net sales and historical COGS; credit notes reduce aged receivables; purchase debit notes reduce international supplier outstanding; returns card uses return revenue facts rather than inventory cost movements.
